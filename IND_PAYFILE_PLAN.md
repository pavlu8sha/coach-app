# Индивидуальные / вратарские: переход на файл оплат

Статус: ветка ind-payfile, код ещё не переключён. Старая таблица «Индивидуальные | Вратарские» — только чтение.

## Решения
- Занятия (дата, время, вратарская, тема, вместимость) — лист «ИНДИВИДУАЛЬНЫЕ ЗАНЯТИЯ» в AdminApp.
- Записан на занятие — строка в блоке «Индивидуальные / Вратарские» файла оплат: дата, имя, сумма пустая.
- Оплата — сумма 50 ₾ в той же строке (claim существующей строки по дате и имени).
- Отмена записи — строка удаляется; отмена оплаты — сумма очищается, строка остаётся.
- Создание занятия не пишет ничего в файл оплат; строки появляются при записи.
- Старые занятия читаются из старой таблицы (только чтение), история в IND_LOG остаётся.

## Что меняется (шаги, каждый отдельным коммитом)
1. Создание занятий → AdminApp (indCreateEvent_, indWeeklyCreate, indParseRaw_ читает новый лист).
2. Записи и оплаты → файл оплат (appIndPay, appIndUnpay, appIndRemove, indSaveMarks_, indRoster_).
3. Должники и страница «Индивидуальные» → файл оплат (Debtors.js, indDebts_, WebApp.js).
4. Сверка (IndReconcile.js) и Warmup.js → под новую модель.

Шаги 1 и 2 нельзя выпускать по отдельности: без шага 2 отметки и оплаты новых занятий не работают.
