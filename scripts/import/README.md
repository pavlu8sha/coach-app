# Импорт из таблиц в базу

Таблицы не читаются напрямую: владелец экспортирует нужный лист в CSV (Файл → Скачать → CSV), скрипт читает файл.

## Реестр игроков

1. Экспортируйте лист «РЕЕСТР ИГРОКОВ» в CSV.
2. Проверка без записи: `node scripts/import/run-players.mjs registry.csv`
3. Запись (сначала на тестовом проекте): задайте `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `CLUB_ID` и запустите с `--write`.

Скрипт не пишет, если есть строки с ошибками. Ключ сервиса — только в переменных окружения, в репозиторий не кладём.
