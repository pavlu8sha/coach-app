# CLAUDE.md

## Правила проверки
- Проверка считается пройденной только с полным выводом. «Прошло» без вывода
не считается.
- Перед запуском код проверяет вторая модель в чистой сессии по списку из
пяти сценариев. Находки закрываются тестами.
- Фича начинается с файла условий приёмки. Тесты пишутся от условий. Код
после тестов.
- База в проверках та же, что в проде. Миграции сверяются с моделями.
Красная проверка, деплоя нет.
- После каждого инцидента запись в «Уроки»: дата, что, почему, правило, чем
ловится. Уроки читаются перед каждой задачей.

## Уроки

Этот раздел читается перед каждой задачей. После каждого инцидента сюда
добавляется запись по формату ниже.

Формат записи:
- **Дата:** ГГГГ-ММ-ДД
- **Что:** что произошло
- **Почему:** первопричина
- **Правило:** что делать теперь
- **Чем ловится:** какая проверка, тест или сверка поймает это в будущем
