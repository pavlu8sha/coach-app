# CLAUDE.md

## Правила проверки
- Проверка считается пройденной только с полным выводом. «Прошло» без вывода
не считается.
- Независимая проверка второй моделью не выполняется (решение владельца
2026-11-11: слишком дорого по токенам). Риски закрываются тестами и полным
прогоном `scripts/run-db-tests.sh`; в описании PR честно указывать, что
независимой проверки не было.
- Фича начинается с файла условий приёмки. Тесты пишутся от условий. Код
после тестов.
- База в проверках та же, что в проде. Миграции сверяются с моделями.
Красная проверка, деплоя нет. Права на функции и таблицы проверять на базе с
привилегиями по умолчанию Supabase (`alter default privileges ... grant ...
to anon, authenticated, service_role`), а не только на базе без них.
- После каждого инцидента запись в «Уроки»: дата, что, почему, правило, чем
ловится. Уроки читаются перед каждой задачей.
