# Рейтинг, баллы и достижения — черновик правил (Issue #18)

Статус: **черновик для согласования с тренером.** Все числа — стартовые, их правит клуб. Начато: правила и перенос истории (посещаемость и матчи) — миграция `0012`, `scripts/import/run-rating.mjs`. Навыки, рекорды, уровни и экраны — не начаты.

## Что начисляет баллы (согласовано 2026-10-22)

1. **Посещаемость тренировок.**
2. **Результаты на матчах.**
3. **Освоение навыков.**
4. **Личные рекорды.**

## Правила начисления (черновик)

| Источник | Событие | Баллы | Примечание |
|---|---|---|---|
| Посещаемость | Пришёл на тренировку | +1 | Только для отмеченных «пришёл» |
| Посещаемость | Пропуск по уважительной причине | 0 | Не снижает баллы |
| Посещаемость | Пропуск без причины | 0 | Без штрафа, по принципу из Issue #18 |
| Матчи | Участие в матче | +2 | Вне зависимости от результата |
| Матчи | Победа команды | +3 | Для игрока, который был в составе |
| Матчи | Ничья | +1 | |
| Навыки | Освоение навыка | +N (1–3 по уровню) | Список навыков и уровни задаёт тренер |
| Рекорды | Личный рекорд (например, спринт) | +N | Вносит тренер, пишется значение и дата |

Каждое начисление хранит `rule_id`, дату и текст объяснения. Родитель видит «за что» и «когда».

## Уровни

Пороги по сумме баллов за сезон, например: 0–20 — старт, 21–50 — развитие, 51+ — опытный. Названия и пороги задаёт клуб.

## Групповой рейтинг

Предлагаемое правило: **сумма баллов игроков группы** (как выбрано). Риск: большая группа сильнее маленькой. Альтернатива для обсуждения: средний балл на игрока.

## Роли и доступ

| Роль | Личный прогресс ребёнка | Групповой рейтинг |
|---|---|---|
| Ребёнок | Свой | Да |
| Родитель | Своих детей | Да |
| Тренер группы | Детей своей группы | Да |
| Другие родители | **Нет** (предложение, отличается от выбора в ответах: см. ниже) | Да |
| Администратор | Все | Да |

**Отличие от ответа:** в ответах выбрано «Другие родители» для личного прогресса. Предлагаю закрыть это, потому что Issue #18 требует, чтобы индивидуальная публичность была выключена по умолчанию. Если клуб хочет показывать, это нужно включить явно и по согласию родителей.

## Режимы клуба

- Личный прогресс (по умолчанию).
- Групповой рейтинг.
- Индивидуальный публичный рейтинг — выключен по умолчанию.

## Приёмка

- Каждый балл объясним: есть правило и дата.
- Уважительная причина не снижает баллы.
- Другие родители видят только групповой рейтинг, если клуб не включил иное.
