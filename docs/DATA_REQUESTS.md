# Данные родителя: отзыв согласия, выгрузка, удаление (2026-10-23)

Механика сделана в миграции `0025_consent_controls.sql`. **Юридические вопросы (сроки хранения, что именно удалять, ответ в срок) решает владелец после проверки текста согласия** (`docs/CONSENT.md`); ниже описано, что делает приложение сейчас.

## Что может родитель (Профиль → «Мои дети» / «Мои данные»)

- **Отозвать согласие по ребёнку** (`revoke_consent`): связь отключается сразу, ребёнок и его данные пропадают из приложения родителя. В базе остаётся отметка `consent_revoked_at` как запись о факте отзыва; прежний запрос на связь удаляется, поэтому родитель может подать новый запрос и дать согласие заново. Действие попадает в `audit_log`.
- **Скачать свои данные** (`export_my_data`): один JSON: аккаунт (имя, Telegram ID), дети с версиями и датами согласия, запросы на связь, а по детям с действующим согласием — посещаемость, баллы, платежи, участие в матчах. Чужих данных там нет. Если файл не скачивается (в части версий Telegram), есть кнопка «Скопировать данные».
- **Запросить удаление данных** (`request_data_deletion`): создаётся запрос; одновременно открыт может быть один.

## Что делает администратор (вкладка «Запросы», блок «Запросы на удаление данных»)

- **«Удалить данные»** (`erase_parent`, с подтверждением): удаляет связи родителя с детьми (`player_guardians`), его запросы (`link_requests`) и очищает имя в `users`; запрос получает статус «выполнено», действие пишется в `audit_log`.
- **«Отклонить»** (`reject_data_request`): с необязательной причиной, которую увидит родитель.
- Для администратора и тренера удаление не выполняется (за ними числятся действия в журналах).

## Что НЕ удаляется автоматически (решение владельца)

- **Данные игроков** (имя, группа, посещаемость, баллы, платежи): они принадлежат клубу, а не родителю. Нужен ли отдельный порядок удаления данных ребёнка, определяется юридически.
- **Строка `users` с Telegram ID:** нужна для входа и целостности (на неё ссылаются журналы). Если нужно удалить и её, это делается вручную.
- **Учётная запись в Supabase Authentication** (там хранится имя из Telegram в метаданных): удаляется вручную в разделе Authentication → Users.
- **Журнал аудита** (`audit_log`): хранит факты действий, без содержимого платежей.

## Открытые вопросы к владельцу

1. Срок, за который нужно обработать запрос на удаление (сейчас сроков нет, запрос ждёт администратора).
2. Удалять ли данные ребёнка по запросу родителя, и если да — какие.
3. Нужно ли уведомление родителю о выполнении запроса (требует уведомлений через бота, пункт 6 handoff).
4. Юридическая проверка текста согласия и политики конфиденциальности.
