# Роли тренеров: план (2026-10-23)

Статус: ответы Павла получены, реализация по шагам, каждый шаг — отдельный PR. Миграции применяет владелец в Supabase SQL Editor; к боевой БД я не обращаюсь.

## Что может тренер (решения Павла)

1. **Посещаемость.** Занятие берётся из расписания группы (`weekly_schedule`). Отметки «был / не был / уважительная причина». Править можно и задним числом.
2. **Баллы.** Автоматические: за посещаемость, за участие в матче, за победу/ничью, за голы. Ручные: тренер отмечает, чем выделился игрок.
3. **Матчи.** Тренер отмечает, кто играл, вносит счёт и голы игроков.
4. **Контакты родителей** детей своей группы: видит.
5. **Назначение тренеров:** вход через Telegram; администратор назначает группы тренеру кнопкой в приложении.
6. Платежей тренер не видит (как в базе).

## Принципы реализации

- Тренер пишет **только через функции** (`security definer`), прямые права на запись в `sessions`, `attendance`, `point_events` у тренера закрываются. Иначе можно обойти правила начисления через API.
- Автобаллы пересчитываются функцией при каждой отметке (исправление задним числом не оставляет лишних баллов). Это единственное исключение из «журнал баллов только добавляется»: функция удаляет и добавляет **только** автоначисления того занятия/матча, который правят.
- Занятия создаются по ключу `ATT|<дата>` как при импорте, дубликатов с историей нет. Дата занятия — по времени Тбилиси.
- Каждая функция: проверка роли, pgTAP-тест «чужая группа / родитель / не тренер», `grant`/`revoke` явно.

## Вопросы с вариантами по умолчанию

- **Баллы за гол:** по умолчанию +1 за каждый гол (правило `match_goal`, число правит клуб).
- **Ручные баллы:** по умолчанию от +1 до +5 за раз, комментарий обязателен, отрицательных нет.
- **Состав матча:** по умолчанию игроки группы; если у матча есть список участников (`match_fees`), берём его.
- **Матчи:** тренер может и добавить матч своей группы, и заполнить результат у существующего (решение Павла 2026-10-23); администратор и импорт тоже.
- **Контакты:** в базе нет телефонов, только имя в Telegram и Telegram ID. Тренер видит имя родителя, ребёнка и ссылку на чат в Telegram. Подтверждено Павлом: Telegram достаточно.
