# Баллы только в профиле игрока: условия приёмки

Решение владельца 2026-11-13: с главного экрана убрать баллы, оставить их только в профиле игрока (вкладка «Баллы»).
Миграций нет, права и данные не меняются, только веб.

## Условия

1. **Главная родителя без баллов.** В карточке ребёнка нет числа баллов, подписи «балл/балла/баллов», истории начислений,
   строки «Всего накоплено» и пустого состояния «Баллов пока нет». Остаются имя, группа, «Матчей сыграно», кнопка
   «Профиль игрока», статусы запросов, «Добавить ещё одного ребёнка». У нескольких детей заголовок «Мои дети» как раньше.
2. **Главная ребёнка без баллов.** Те же исключения. Остаются имя, группа, «Матчей сыграно», кнопка «Мой профиль».
   Заголовок экрана и вкладка нижнего меню больше не называются «Мои баллы».
3. **Баллы доступны в профиле.** Вкладка «Баллы» в профиле игрока (родитель и ребёнок) показывает журнал как раньше.
4. **Лишних запросов нет.** Главные экраны не читают `points_ledger`.
5. **Остальное без изменений.** Экраны тренера и админа, вход в профиль, «Назад», ссылки на сборы, привязка ребёнка.
