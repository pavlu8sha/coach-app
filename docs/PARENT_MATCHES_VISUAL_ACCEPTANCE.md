# Матчи у родителя: светофор результата, «Играл / Не играл», оценка за матч

Условия приёмки (27.11.2026, просьба Павла; ответы: оценка и «★ Лучший» своему ребёнку показываем, одна пометка «Не играл», голы своего ребёнка остаются, оба экрана одним PR). Макет: `/mnt/project-files/parent-matches/mockup.png`. Миграций нет: родитель и так читает свои строки `match_players` целиком (политика `match_players_read`, 0042), включая `performance_rating` и `best`; оценку в «Баллах» он уже видит. Реализация: общий компонент строки результата, экраны `PlayerProfile` (Ребёнок → Матчи), `Matches` (вкладка «Матчи» родителя), `ChildMatches` (экран самого ребёнка).

## Общие правила

О1. Строка результата (матч со счётом) имеет цветную полосу слева: победа зелёная, ничья жёлтая, поражение красная; рядом со счётом словесная метка «Победа» / «Ничья» / «Поражение» (цвет её тоже красит, но не единственный признак). Матч без счёта: нейтральная полоса и метка «Без счёта». В сводке форма последних матчей остаётся буквами В / Н / П.
О2. Пометка участия своего ребёнка: «Играл» или «Не играл». «Не играл» ставится только там, где сервер отдал строку с `played = false`, либо строки нет, а матч не раньше первой записи ребёнка в `match_players` (до первой записи ребёнка в команде не было: матч не показывается в карточке ребёнка, а в общей вкладке пометки нет). Для ребёнка совсем без записей пометок нет.
О3. Голы: «голы: N» только у сыгравшего и только при N > 0, как сейчас. Голов других детей нигде нет.
О4. Оценка за матч: у сыгравшего с `performance_rating` не null показывается «Оценка N из 5» (пять точек, N закрашены) и «+B б.», где B = min(оценка + 1 если лучший, 6); баллы показываются только у матча со счётом. Нет оценки (матчи до 01.12, оценка не выставлена): ничего не рисуется, не «0» и не «—». У «Не играл» оценки и звезды нет.
О5. «★ Лучший» только если у своего ребёнка `best = true` и `played = true`. Оценок, звёзд и пометок других детей на экранах нет.
О6. Сводка результатов: плитки «побед», «ничьих», «поражений» тех же цветов (зелёная, жёлтая, красная) и форма последних матчей В/Н/П; числа считаются как раньше (`teamResults`).
О7. Ничего из существующего не убирается: фильтры, турниры, «Подтвердите участие», месяцы, итоги команды, «Без счёта», турниры без матчей остаются.

## Карточка ребёнка → «Матчи» (PlayerProfile)

К1. Список: матчи команды ребёнка (команда = группа или группа без суффикса -A/-B/-C, как `teamNames`) со счётом или уже прошедшие, плюс матчи другой команды, где у ребёнка есть строка `match_players`. Новые сверху, группировка по месяцам: `details`, самый свежий месяц открыт, в заголовке «N матч/матча/матчей».
К2. Сверху плитки: «матчей команды», «играл», «голов (его)»; под ними плитки побед/ничьих/поражений и форма последних пяти. Числа берутся из показанного списка (со счётом).
К3. Каждая строка по О1–О5. Заголовок строки: «Соперник» (как раньше «U10 — соперник», команда сохраняется, если соперник неизвестен).
К4. Пустое состояние: у ребёнка нет записей об участии: «Отмеченных матчей пока нет» (текст сохраняется), без плиток.
К5. Раздел «Обзор»: строки «Сыграно матчей … · голов: …», «Баллы», «Последняя тренировка» не меняются.
К6. Ошибка загрузки матчей: прежний экран с повтором; во время загрузки вкладка не пустая (`Loading` профиля, как сейчас).

## Вкладка «Матчи» родителя (Matches)

В1. Сводка («Сыграно: N») показывает цветные плитки по О6; строки «Мячи» и «Лучший матч» остаются.
В2. Строки «Результаты» по О1; в подписи для каждого своего ребёнка: «Имя: играл / не играл», голы, ★ Лучший, оценка по О3–О5 (имя только при нескольких детях, как сейчас).
В3. Для матчей без строки участия и до первой записи ребёнка пометки нет (О2).
В4. Блок «Подтвердите участие», фильтры, турниры, ошибки проверки счёта не меняются.

## Экран ребёнка (ChildMatches)

Р1. Строки результатов получают ту же полосу и метку (О1); добавляется «не играл» (О2), оценка и ★ по О4–О5 для самого ребёнка.

## Права и данные

П1. Новых запросов к чужим данным нет: `match_players` читается с `player_id` своих детей, колонки `best, performance_rating` добавлены к уже существующему запросу; проверка тестом: строка чужого ребёнка в ответе не влияет на экран.
П2. Миграций, функций и RLS-правок нет; preflight не меняется.
