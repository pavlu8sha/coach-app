# Один матч — один экран, PR 3: убрать отдельный раздел «Матчи с подтверждением»

Продолжение `docs/MATCH_UNIFIED_SCREEN_ACCEPTANCE.md` (PR 1, #839) и `docs/MATCH_UNIFIED_SCREEN_PR2_ACCEPTANCE.md` (PR 2, #842, миграция 0227 применена 27.11). Миграций нет, сервер и родительский интерфейс не меняются.

## Экран

М1. В меню «⋯» экрана «Матчи» нет пункта «Матчи с подтверждением» и бейджа с числом предстоящих. У администратора в меню остаётся «Новое событие»; у тренера меню «⋯» не показывается (пунктов нет).
М2. Отдельного списка «Матчи с подтверждением» нет. Матчи с подтверждением во всех состояниях (черновик, опубликован, отменён) остаются в общем списке «Матчи» и открываются единым экраном с разделами «Состав и ответы» и «Результат» (как после PR 1).
М3. «+ Матч» → «Создать матч с подтверждением» открывает форму «Новый матч»; после создания открывается единый экран нового матча, раздел «Состав и ответы», с прежним сообщением о создании (число добавленных игроков, ошибка автозаполнения). «Назад» возвращает в общий список «Матчи», где новый матч виден.
М4. Тексты, отсылавшие к разделу «Матчи с подтверждением», ссылаются на «Состав и ответы».
М5. Создание, публикация, отмена, перенос, права тренера и администратора, поиск игрока, родительский интерфейс не меняются.

М6 (после PR 3, проверка Павла на iPhone 27.11). В разделе «Результат» кнопка «Править состав» показывается только если в составе есть игроки, которых можно убрать из матча (добавленные вручную): приглашённых она не трогает, и без таких игроков нажатие ничего не меняло. Если в составе одни приглашённые, кнопки нет, вместо неё пояснение «Приглашённых добавляют и убирают в разделе «Состав и ответы»; здесь отмечается, кто играл».

М7 (решение Павла 27.11). Матч теперь один вид, слова «с подтверждением» в интерфейсе нет: кнопка тренера называется «Создать матч», подпись раздела родителя для экранного чтения — «Прошедшие матчи». Работа и поведение не меняются.

## Проверки

- vitest: нет пункта меню и бейджа ни у тренера, ни у администратора; у тренера нет кнопки «⋯», у администратора только «Новое событие»; после создания матча открывается единый экран с сообщением, «Назад» возвращает в список; тексты по-новому.
- Тесты бывшего экрана «Матчи с подтверждением» (`MatchRsvp.test.tsx`, `MatchRsvpFee.test.tsx`, `CoachRsvpLoad.test.tsx`) перенесены на экраны, которые остались: форму создания и карточку матча («Состав и ответы»); число и смысл проверок не уменьшаются.
- `npx vitest run`, `npm run build`; мобильная проверка 390 px (светлая и тёмная темы) списка без меню и созданного матча.
