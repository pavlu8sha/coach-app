# Сверка экранов: старое приложение и новое (2026-10-26)

Основа: HTML старого приложения (`Index.html`, `Admin*.html`, `Cash.html`, `Pay.html`, `Debt.html`, `Games*.html`, `Kit.html`, `Ind.html`, `Camp.html`) и текущий `master`. Порядок разделов — как в меню старого приложения: отметки, игроки, оплаты, матчи. Устройства: тренеры — телефон; администраторы — телефон, ноутбук, iPad (адаптивная вёрстка — PR «Адаптивная вёрстка для планшета и ноутбука»).

## 1. Отметки (тренер и администратор)
| Старое | Новое | Пробел → план |
|---|---|---|
| Группа + дата, переключатель «Группы / Индивидуальные», «Показать все группы» (доп./перенесённая тренировка) | «Занятия»: группа и день по расписанию; тренер видит все группы (0042) | Индивидуальные и дополнительные отмечаются на своих экранах («Ещё»). План: ввести в «Занятия» вкладку «Индивидуальные», чтобы тренер отмечал их там же, где группы |
| «Все были», «Сбросить», шкала, счётчики были/не были/осталось, закреплённая кнопка «Сохранить» | Есть («Отметить всех «Был»», шкала, счётчики, панель сохранения) | Уважительная причина — новое |
| Код доступа, без входа через Telegram | Вход через Telegram | Лучше |

## 2. Игроки (администратор)
| Старое | Новое | Пробел → план |
|---|---|---|
| Список: поиск по ФИ, ID, группе; фильтры группа, статус, год рождения, «только не оплатившие» | Есть те же фильтры и статус оплаты | — |
| Карточка игрока одним экраном с вкладками: абонемент и история платежей, оплата за другой месяц/группу, дополнительные, индивидуальные и вратари, экипировка, сыгранные матчи, взносы, изменить данные/дату рождения | Карточка показывает только абонемент и данные | **Главный пробел.** План: вкладки в карточке — «Абонемент», «Индивидуальные», «Дополнительные», «Экипировка», «Матчи и взносы», «Баллы» |
| «Добавить игрока» с проверкой тёзки и «из воронки» | Добавление с проверкой тёзки; воронка заменена заявками из бота | — |

## 3. Оплаты (администратор)
| Старое | Новое | Пробел → план |
|---|---|---|
| **Приём оплат** (`Cash.html`): найти игрока по ФИ → видно, что к оплате по абонементу, экипировке, индивидуальным и допам → принять платёж (месяц, способ, дата, комментарий, частичный, «скидка по договорённости») | Платежи по игроку (только абонемент), «Оплаты за месяц» (группа × месяц); экипировка, индивидуальные, допы платятся каждая на своём экране | **Главный пробел.** План: единый экран «Приём оплат» с долгами по всем разделам игрока и оплатой в один шаг |
| «Внесено сегодня» и «Отменить оплату» | Журнал только добавляется; отмена записью с минусом на экране игрока | План: список «Внесено сегодня» с кнопкой «Исправить» (запись с минусом) |
| Оплаты по месяцам и группам (`Pay.html`) | «Оплаты за месяц» + быстрый платёж | Есть |
| Должники (`Debt.html`): фильтр группы, оплата прямо из строки, «Скопировать текст» с шаблоном сообщения родителям | Должники: скидка, списано, создать месяц | Нет оплаты из строки, нет «Скопировать текст», нет фильтра по группе. План: добавить |

## 4. Матчи
| Старое | Новое | Пробел → план |
|---|---|---|
| Игры: состав, счёт, голы, сторона, «Копировать состав» | «Матчи»: состав, счёт, голы, лучший игрок, события, турниры | Проверить «Копировать состав из прошлого матча» |
| Взносы за событие, «Массовая оплата» выбранным игрокам (способ и дата для выбранных) | Взносы события по игроку | Нет массовой оплаты. План: «Выбрать всех» + дата и способ |

## 5. Остальные разделы
Экипировка, сборы, индивидуальные, дополнительные, учёт тренеров, статистика — перенесены (см. `docs/STAFF_LAUNCH.md`). Улучшения общие: оплата и посещение в одном экране, понятные ошибки на русском, работа с телефона и ноутбука.

## Порядок работ
1. Приём оплат (единый экран) + «Внесено сегодня».
2. Карточка игрока с вкладками.
3. Должники: оплата из строки, копирование текста, фильтр по группе.
4. Массовая оплата взносов.
5. «Индивидуальные» во вкладке «Занятия».
