# Цены и долг по абонементу: правила (2026-10-23)

Решения Павла от 2026-10-23; расчёт повторяет старое приложение (`Prices.js`, `Debtors.js`). Реализация: миграция `0023_prices_debt.sql`, экраны «Должники» (администратор) и «Оплата» (родитель).

## Правила

- **Цена абонемента:** общая 165 ₾; для группы `weekends` — 130 ₾; индивидуальное занятие — 50 ₾ (в расчёте долга не участвует). Цена действует с месяца начала, прошлые месяцы остаются по своей цене; своя цена группы важнее общей. Цены лежат в таблице `prices` (сейчас засеяны значениями по умолчанию с 2026-09-01).
- **Долг за месяц** = цена абонемента группы минус всё внесённое за этот месяц (`payments`, по месяцу `paid_on`). Не меньше нуля.
- **Скидка** (`subscriptions.discount`): если за месяц что-то внесено, месяц считается оплаченным (как в старом приложении). Скидку отмечает администратор на экране «Должники».
- **Какие месяцы считаются:** с сентября 2026 (`debt_start()`). Текущий месяц — всегда; прошлые — только если за месяц есть строка абонемента, чтобы «новому» игроку не показать долг за месяцы до прихода.
- **Не считаются:** группа «Индивидуальные / Вратарские», неактивные игроки.
- **Родителю** показываются только его дети (действующее согласие) и только после включения администратором настройки `club_settings.parent_debt_enabled = 'true'`. Пока она выключена, родитель долга не видит: у детей со скидкой иначе был бы неверный долг (скидки из старого приложения ещё не перенесены).
- Без пени и штрафов. Под суммой: «Если что-то не сходится, напишите администратору клуба».

- **Списано** (0032): администратор списывает долг игрока за месяц на экране «Должники»; списанный не показывается ни в списке, ни родителю; платежи не меняются, списание можно вернуть.
- **Абонементы на месяц** (0032): кнопка создаёт строки абонементов для активных игроков с группой (без индивидуальных); существующие не трогает. Нужна, чтобы неплательщики попали в долг за месяц.

## Что не входит (следующие шаги)

- Экипировка в рассрочку, индивидуальные занятия, доп. программы как отдельные долги.
- Перенос скидок из старого приложения (сейчас отмечаются вручную на экране «Должники»).

## Известные ограничения

- **Доп. программы:** в импорте оплаты за месяц суммируются по игроку по всем программам, а цена берётся по основной группе. Если ребёнок платит и основную группу, и `weekends`, переплата по доп. программе может закрыть недоплату по основной. Старое приложение учитывало это отдельно (`effPaid_`). Пока администратор сверяет список «Должники» со старым приложением, прежде чем включать показ родителям.
- **Прошлые месяцы:** если у неплательщика за прошлый месяц нет строки абонемента (в импорте строки создавались по внесённым суммам), долг за этот месяц не показывается (безопасная сторона: ложных долгов нет, часть настоящих может не показаться).
