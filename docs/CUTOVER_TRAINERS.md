## 1. Сб 31.10: проверка, что все тренеры назначены
В SQL Editor (только чтение): кто вошёл, но без групп.
```sql
select u.display_name, u.chosen_role, u.created_at::date as вошёл,
       (select count(*) from coach_groups c where c.user_id = u.id) as групп
from users u
where not u.is_admin
order by групп, u.created_at;
```
Каждый тренер должен быть с `групп > 0`. Кто без групп: «Ещё → Тренеры» → найти по имени → назначить. Тренеров 7: Павел и Дима (администратор) уже настроены; остальные пятеро должны появиться в списке после входа.

## 2. Сб 31.10, вечер: финальный импорт и сверка
Порядок и команды: `docs/SYNC_PLAN.md`. Для тренерских разделов нужны:
`run-players` → `run-schedule-log` → `run-attendance` → `run-events` → `run-individual` → `run-rating` (без матчей) → «Ещё → Пересчёт баллов за матчи» → `verify.mjs`.
1. Выгрузить свежие листы в CSV.
2. Каждый скрипт сначала без `--write`, посмотреть отчёт, потом с `--write`.
3. `verify.mjs`: расхождений нет.
4. **После этого не импортируем:** посещаемость (`run-attendance`) и матчи (`run-events`: он перезаписывает состав и голы импортированных матчей, а тренеры теперь правят их в новом приложении).
5. **Продолжаем импортировать** (администраторы работают в старом ещё две недели, ориентир перехода администраторов — **15.11**): игроки (`run-players`), оплаты, **индивидуальные** (`run-individual`: занятия и записи создаёт администратор в старом; импорт не трогает отметки посещения, которые ставят тренеры в новом, и теперь сам ставит признак «вратари»), экипировка, сборы.
6. Взносы за матчи, внесённые администратором в старом приложении за эти две недели, переносятся при переходе администраторов отдельным шагом (важно не затереть состав и голы матчей, правленные тренерами).

## 3. Вс 01.11: наблюдение
Вечером в SQL Editor выполнить `db/ops/trainer_day.sql` (дата по умолчанию — сегодня): по группам видно, кто отметил и сколько. Группы с занятием по расписанию и нулём отметок идут первыми: им нужно напомнить. Ошибки тренеров присылать скриншотом.

## 4. Отключение старого для тренеров (вт–ср, по решению)
Apps Script → Project Settings → Script properties → поменять `APP_PIN` (код тренера). Старые «Отметки» перестанут пускать тренеров, администратор (`APP_ADMIN_PIN`) работает как раньше. Откат: вернуть прежнее значение `APP_PIN`.

## Если что-то пошло не так в воскресенье
- Приложение не открывается у одного тренера: проверить группы (раздел 1), перезайти, при необходимости выбрать роль «Тренер» заново.
- Приложение не работает у всех: тренеры отмечают на бумаге/в чате, владелец вносит отметки позже через «Занятия» администратора (отметка задним числом возможна 21 день). Старое приложение не включаем для посещаемости, чтобы не получить два источника.
- Данные в базе расходятся с таблицей (редкие случаи): `verify.mjs` и запрос из `trainer_day.sql` покажут, где.

## Что тренеры делают только в новом с 01.11
Посещаемость групп, индивидуальные, вратарские и дополнительные, матчи (состав, счёт, голы, лучший игрок), статистика, ручные баллы. Инструкция: `docs/TRAINER_GUIDE.md`.
