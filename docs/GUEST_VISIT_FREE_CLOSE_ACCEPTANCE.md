# Закрыть доп. посещение без оплаты в «Отметках»: условия приёмки

Файл написан до тестов и кода. Просьба Павла 27.11.2026: в «Отметках» (блок «Доп. посещения») закрыть посещение без оплаты там же, не идя в карточку игрока; закрытое без оплаты не должно выглядеть как «Оплачено». Серверная часть уже есть (0221, `session_guest_discount`); миграций и изменений базы нет.

1. Администратор видит у неоплаченного гостя кнопку «Без оплаты». Тренеру кнопка не показывается (функция 0221 только для администратора).
2. Кнопка открывает окно закрытия с игроком, суммой и обязательной причиной (не короче 3 символов, как в Кассе); без причины подтвердить нельзя. Отмена окна ничего не вызывает.
3. После подтверждения вызывается `session_guest_discount(s, p, due = 0, why = причина)`; дата и способ не отправляются. После успеха блок перезагружается и показывает сообщение «Посещение закрыто без оплаты.»; ошибка функции показывается человеческим текстом.
4. Посещение, закрытое без оплаты (`paid = true`, `paid_amount = 0`), показывается как «Закрыто без оплаты» (не «Оплачено», не зелёным «ок»), без суммы-«15 ₾» как оплаченной и без способа оплаты. Обычно оплаченное (`paid_amount` > 0 или пусто у старых записей) выглядит как раньше: «Оплачено (способ)».
5. У закрытого без оплаты администратор видит кнопку «Вернуть в долг» (вызывает `session_guest_set_paid(..., false)`, как раньше «Отменить оплату», с подтверждением; текст без слов про строку с минусом в кассе, платежа не было). У обычно оплаченного остаётся «Отменить оплату» как раньше. Тренер ни ту, ни другую не видит.
6. «Убрать» и оплата Наличные/Перевод у неоплаченного работают как раньше; закрытого без оплаты убрать нельзя (как оплаченного).
7. Частичная скидка (сумма больше 0) остаётся в Кассе и в этой работе не добавляется.
8. Баллы, касса, выручка, база и права не меняются.
