# Плавное окно выбора даты в «Отметках» (пробная правка)

Жалоба Павла 23.11.2026: в «Отметках» при нажатии на строку с датой окно выбора появляется резко, а у выбора группы плавно. Гипотеза: общее правило `styles.css` (`-webkit-appearance: none` для всех полей даты) отключает родное поведение iOS.

1. Поле «Дата» на экране «Отметки» получает класс `ks-date-native`, у которого `appearance: auto`; остальные поля даты в приложении не меняются.
2. Класс уникален (grep по `web/src`), правило использует только стандартные свойства.
3. Горизонтальной прокрутки страницы нет, ширина поля по-прежнему не выходит за экран (проверка Павла на iPhone).
4. Если плавности нет или поле выглядит хуже, правка откатывается; данные и база не затрагиваются, миграций нет.
