# Условия приёмки: 7 правок по скринам Павла (2026-11-16)

Пункты 1-6 и 7 (только карточка игрока), без миграций.

1. Сборы родителя: в Telegram (есть нативная BackButton) своих кнопок «← Назад»/«← Сборы» нет; в браузере одна кнопка «Назад» (BackNav). Системная «Назад» ведёт из карточки в список, из списка на предыдущий экран.
2. Баннер Winter Camp в кабинете родителя: кнопка называется «Записаться» и открывает экран сборов. Названия «Записаться / мои сборы» нет нигде. У гостя кнопки нет.
3. Админка сбора, «Места и ссылка»: поле называется «Адрес публичной ссылки» (не «Имя ссылки»), под ним подсказка, что это часть адреса вида `…startapp=camp_<адрес>`; пусто = публичной ссылки нет. Поведение сохранения не меняется.
4. Расписание: блок «Последние результаты» не показывается гостю (и родителю без привязанных детей). Родителю с детьми, тренеру и админу показывается как раньше; «Ближайшие матчи» видны всем.
5. Гостевая страница Winter Camp: внизу нет кнопки «Запись открыта · @…»; вместо неё текстовая ссылка «Остались вопросы? Написать администратору» (ссылка на чат админа, не `ks-btn`). Кнопка записи в верхней части страницы (кабинет) не меняется.
6. Журнал оплат экипировки: строка «входящего остатка» (`opening_balance`) выводится как «Внесено до начала учёта» один раз и без даты (даты 01.01.2000 нет). Остальные строки журнала как раньше (дата · вид · способ · примечание). Данные в базе не меняются.
7. Карточка игрока группы «Индивидуальные / Вратарские»: вкладка «Абонемент» не показывает месяцы, долг и кнопки «Внести платёж» / «Закрыть без оплаты», а показывает пояснение «У этой группы нет абонемента: оплата идёт за занятия» (оплата на вкладке «К оплате»). Распознавание группы одной общей функцией `hasSubscription(groupName)` (регистр и пробелы не важны). Остальные группы без изменений.
