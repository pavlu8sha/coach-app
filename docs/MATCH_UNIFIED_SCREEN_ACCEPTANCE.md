# Один матч — один экран: условия приёмки

Решение владельца 2026-11-26. План: три PR. Этот файл ведёт условия по этапам. Данные и серверные функции не меняются.

## PR 1. Единый вход и единый экран

Тесты: `web/src/screens/CoachMatches.test.tsx` (блок «Единый экран матча»).

1. Общий список «Матчи» показывает матчи с подтверждением во всех состояниях: черновик (пометка «Черновик»), опубликованный, отменённый (пометка «Отменён»). Матчи без подтверждения (legacy) показываются как раньше.
2. Открытие матча с подтверждением из общего списка ведёт на единый экран с двумя постоянными разделами: «Состав и ответы» (существующий `RsvpDetail`) и «Результат» (существующая `MatchForm`). Бизнес-логика и запросы не копируются, экраны переиспользуются.
3. Раздел по умолчанию определяется по `matches.starts_at` как по моменту времени, а не по дате `played_on` и не по поясу телефона: до начала «Состав и ответы», с начала «Результат».
4. Пользователь вручную открывает любой раздел в любое время и возвращается обратно; несохранённые правки результата при переключении не теряются.
5. Черновик и отменённый матч: раздел «Результат» открывается, но вместо формы показывает пояснение, что результат вносится после публикации и начала матча (запись результата в черновик или отменённый матч не предлагается).
6. Матч без подтверждения (legacy) открывается прежней формой, без разделов.
7. Старый пункт меню «Матчи с подтверждением» работает как раньше (список и карточка).
8. Ошибка чтения приглашений в форме результата показывается явной ошибкой с «Повторить»; полный состав группы как запасной вариант не показывается (поправка к #835).
9. Родительский интерфейс, база, серверные функции, баллы, взносы и уведомления не меняются.
10. Ошибки загрузки не маскируются пустым составом (сохраняются состояния loading / error / retry обоих разделов).
11. Нативная кнопка «Сохранить матч» видна только когда открыт раздел «Результат».
12. Приоритет пометки в списке: «Отменён», затем «Черновик», затем счёт, затем «Предстоит»/«Без счёта». Отменённый матч с сохранённым счётом показывает «Отменён», а не счёт.
13. «Состав и ответы» загружается всегда (скрытым, если открыт «Результат»); форма результата строится по свежей строке матча и не показывается, пока она не прочитана; статус «Отменён»/«Черновик» из «Состава» доходит до «Результата».
14. Если в «Составе» изменились данные матча или приглашённые, форма результата перечитывается; при несохранённых отметках сохранение заблокировано до «Обновить форму», save_match не уходит со старыми датой, соперником и составом.
15. Бейдж пункта «Матчи с подтверждением» считает только опубликованные будущие матчи.
16. Вкладки: aria-controls/id, tabindex, переключение стрелками.
