# Условия приёмки: выгрузка заказов экипировки в CSV (запрос Павла 09.11)

Нужно: Дима (не владелец базы) должен получать из приложения список заказов по вещи, например «Дождевик»: кто заказал,
какой размер, сколько. Для отправки в пошив. Без доступа к базе и без SQL.

Эталон результата: запрос `db/ops/readonly-raincoats-2026-11-09.sql` (его результат Павел признал нужным). Файл из приложения
при фильтре «Товар: Дождевик» должен содержать те же строки и те же колонки.

Экспорт доступен только там, где уже доступен экран «Экипировка» (администратор). Новых прав и новых RPC нет: читаются те же
таблицы тем же запросом, что и экран.

## Условия
1. На экране «Экипировка» рядом со списком есть кнопки «Скачать CSV» и «Скопировать» (копирование нужно для Mini App, где
   скачивание файла может быть закрыто).
2. Выгружаются ВСЕ заказы клуба, а не только те, что загружены на экран (экран показывает последние 500). К ним применяются те же
   фильтры экрана (поиск, группа, товар, локация, выдача, вкладка).
3. Одна строка файла равна одной вещи заказа. Если выбран фильтр «Товар», в файл попадают только строки этого товара
   (у заказа «Дождевик + Форма» при фильтре «Дождевик» остаётся только дождевик).
4. Колонки как в эталонном запросе, в том же порядке: «дата заказа», «номер», «игрок», «группа», «локация», «вещь», «размер»,
   «количество», «id заказа». Других колонок нет.
5. Пустые значения (размер, группа, локация, номер, дата) выгружаются пустой ячейкой, а не «null», «не указан» или «Без группы».
6. Порядок строк как в эталоне: по дате заказа, затем по имени игрока; внутри заказа порядок вещей сохраняется.
7. Формат: разделитель «;», кавычки по правилам CSV (значения с «;», кавычкой или переводом строки берутся в кавычки,
   кавычка удваивается), первая строка с названиями колонок, кодировка UTF-8 с BOM, чтобы Excel открыл кириллицу.
8. Значения, начинающиеся с `=`, `+`, `-`, `@`, экранируются апострофом, чтобы таблица не исполнила их как формулу.
9. Если подходящих строк нет, файл не создаётся, рядом с кнопками сообщение «Нет заказов по выбранным фильтрам.».
10. Пока идёт загрузка всех заказов, кнопки неактивны. Ошибка загрузки видна рядом с кнопками.
11. Имя файла: `equipment-ГГГГ-ММ-ДД.csv` (сегодняшняя дата, как в остальном приложении).
12. Экспорт ничего не пишет в базу и не вызывает RPC.
13. Копирование пишет тот же текст, что и файл, без BOM; успех и ошибка видны рядом с кнопкой.

## Условия: Telegram Mini App (сообщение Павла 09.11, скриншот с iPhone)
Баг: в Mini App «Скачать CSV» открыл файл поверх приложения (таблица вместо экрана), кнопка «Назад» перестала работать.
Причина: переход по blob-ссылке в окне Telegram уводит окно со страницы приложения; атрибут `download` там не работает.
14. Внутри Telegram Mini App ссылка на файл не открывается и окно приложения не меняется. «Скачать CSV» передаёт файл через системное
    меню «Поделиться» (`navigator.share` с файлом: оттуда его можно сохранить в «Файлы»). Вне Telegram работает обычное скачивание (п. 11).
15. Если телефон не умеет делиться файлами, экран не меняется, рядом с кнопкой сообщение, что в Telegram файл скачать нельзя и нужно
    нажать «Скопировать» или открыть приложение в браузере.
16. Закрытие меню «Поделиться» без выбора (отмена) ошибки не показывает. Другая ошибка меню показывает сообщение с советом нажать
    кнопку ещё раз или «Скопировать».
