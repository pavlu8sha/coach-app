# Условия приёмки: выгрузка заказов экипировки в CSV (запрос Павла 09.11)

Нужно: Дима (не владелец базы) должен получать из приложения список заказов по вещи, например «Дождевик»: кто заказал,
какой размер, сколько. Для отправки в пошив. Без доступа к базе и без SQL.

Экспорт доступен только там, где уже доступен экран «Экипировка» (администратор). Новых прав и новых RPC нет: выгружаются те
же заказы, которые экран уже загрузил.

## Условия
1. На экране «Экипировка» рядом со списком есть кнопки «Скачать CSV» и «Скопировать» (копирование нужно для Mini App, где
   скачивание файла может не работать).
2. Выгружается то, что видно после фильтров экрана (поиск, группа, товар, локация, выдача, вкладка). Закрытые фильтром заказы
   в файл не попадают.
3. Одна строка файла равна одной вещи заказа. Если выбран фильтр «Товар», в файл попадают только строки этого товара
   (у заказа «Дождевик + Форма» при фильтре «Дождевик» остаётся только дождевик).
4. Колонки: «Дата заказа», «Номер», «Игрок», «Группа», «Локация», «Вещь», «Размер», «Количество», «Надпись», «Статус»,
   «Оплачено», «Сумма заказа», «Выдано».
5. Пустой размер выгружается как пустая ячейка, а не как «null» или «не указан»; игрок без группы получает «Без группы»;
   заказ без даты получает пустую дату.
6. Формат: разделитель «;», кавычки по правилам CSV (значения с «;», кавычкой или переводом строки берутся в кавычки,
   кавычка удваивается), первая строка с названиями колонок, кодировка UTF-8 с BOM, чтобы Excel открыл кириллицу.
7. Значения, начинающиеся с `=`, `+`, `-`, `@`, экранируются апострофом, чтобы таблица не исполнила их как формулу.
8. Если после фильтров строк нет, кнопки неактивны, файл не создаётся.
9. Имя файла: `equipment-ГГГГ-ММ-ДД.csv` (сегодняшняя дата, как в остальном приложении).
10. Экспорт ничего не пишет в базу и не вызывает RPC.
11. Копирование пишет тот же текст, что и файл (с «;» как разделителем); успех и ошибка видны рядом с кнопкой.
