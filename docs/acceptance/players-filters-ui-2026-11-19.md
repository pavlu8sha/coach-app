## Условия
### Шапка и панель
1. **«+ Добавить» в шапке.** Рядом с заголовком «Игроки» малая кнопка «+ Добавить», открывает форму нового игрока (как раньше). В теле экрана отдельной кнопки нет.
2. **Одна строка управления.** Под поиском: кнопка «Фильтры» (при выбранных фильтрах «Фильтры · N», `N` считает группу, статус не по умолчанию и годы как один фильтр каждый) и быстрый чип «Не оплатили» (`aria-pressed`, заменяет переключатель «Только не оплатившие»). Селекты группы и статуса и чипы годов на странице больше не показываются.
3. **Пилюли выбранного.** Под панелью для каждого выбранного фильтра (группа, статус кроме «Активные», каждый год) показана пилюля с названием и кнопкой «✕» (`aria-label` «Убрать …»); нажатие снимает только этот фильтр. Если выбранного нет, строки пилюль нет.

### Окно «Фильтры»
4. **Содержимое.** Нижнее окно (`role="dialog"`, `aria-modal`, закрывается Esc, фоном и кнопкой «Показать»): выбор группы («Все группы» + группы), статус («Активные», «На паузе», «Ушли», «Все»), годы рождения чипами (можно несколько, «без даты» при наличии игроков без даты), «Сбросить», «Показать N» (N — сколько игроков в списке с текущими фильтрами).
5. **Применение сразу.** Изменение в окне сразу меняет список (черновика нет); «Показать» только закрывает окно. «Сбросить» возвращает группу «Все», статус «Активные», годы пусто (поиск и «Не оплатили» не трогает).
6. **Прокрутка и доступность.** Пока окно открыто, фон не прокручивается (`useBodyScrollLock`); цели нажатия ≥ 44 px; на 320–430 px нет горизонтальной прокрутки; светлая и тёмная тема.

### Сохранённое поведение
7. **Логика та же.** Поиск по ФИ, ID и группе; фильтры группы/статуса/года/«не оплатили» дают тот же список, что раньше; счётчик в заголовке списка и «N игр.» в группах без изменений; пустое состояние «Никого не нашли».
8. **Состояние.** Фильтры по-прежнему хранятся в записи навигации списка и возвращаются при «Назад» из карточки; поиск на диск не пишется.
9. Остальные экраны («Матчи», «Оплаты», «Ещё», родительские) не затрагиваются.

## Проверки (автотесты, Vitest)
«+ Добавить» в шапке открывает форму (1); нет селектов и годов на странице, есть «Фильтры» и «Не оплатили» с `aria-pressed` (2); счётчик «Фильтры · N» (2); пилюли появляются и снимаются по «✕» (3); окно: открытие, выбор года/группы/статуса меняет список сразу, «Показать N», «Сбросить», закрытие Esc (4, 5); чип «Не оплатили» оставляет должников (7); поиск по ID, статус «Ушли», 101 игрок, без абонемента, карточка (7). Полный `npx vitest run`, `tsc`, `npm run build`.
