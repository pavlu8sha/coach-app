# Визуальная проверка маркеров календаря (#734)

Статический макет `harness.html` на реальных токенах `web/src/ui/tokens.css` (разметка ячейки повторяет `ParentCalendar.tsx`): сверху «Было» (точки 5 px), ниже «Стало» (ромб и круг 8 px) и легенда; выбранный день с подложкой `--ks-primary-subtle`. Открыть `?theme=dark` для тёмной темы.
Скриншоты: `markers-{320,375,430}-{light,dark}.png` (×2 по плотности). Это не живое приложение и не шрифт iOS; Telegram и реальные данные не проверялись.
