# Условия приёмки: привязанный ребёнок без группы в «Расписании» и «Матчах» (#733)

Источник: аудит #693 (этапы «Расписание» и «Матчи», 19.11.2026), Issue #733 с уточнением приёмки. Master `55d704aa`.
Область: только родительский интерфейс `web/src/screens/Schedule.tsx` (раздел «Группы» у родителя) и `Matches.tsx`. Не меняются: назначение групп, membership, привязки, RSVP, доступы, RLS, RPC, миграции, данные.

## Определения
- **Нет детей:** у пользователя нет ни одной активной связи с ребёнком (`player_guardians`, `consent_revoked_at is null`).
- **Ребёнок без группы:** связь есть, но у игрока нет группы (в «Расписании» `group_id` пуст, в «Матчах» нет названия группы).

## Условия

### Расписание (Schedule, родитель, `all = false`)
1. **Нет детей.** Показывается прежнее пустое состояние («Пока пусто», «Расписание появится, когда администратор подтвердит связь с ребёнком»); сценарий #730 для родителя без детей не меняется.
2. **Все дети без группы.** Показывается отдельное состояние с заголовком «Группа ещё не назначена» и именами детей. Текст не говорит, что связь не подтверждена, и не содержит слов «подтвердит связь».
3. **Часть детей с группой, часть без.** Карточки групп показываются как раньше. Дети без группы не исчезают: отдельная информационная карточка «Группа ещё не назначена» с их именами идёт после групп, это не фиктивная группа, расписания и матчей в ней нет.
4. **Все дети с группами.** Вывод не меняется: карточки групп, тренировки, ближайшие матчи, результаты, список детей группы.
5. **Администратор (`all = true`)** и гость (`all`) не затрагиваются: карточка «Группа ещё не назначена» им не показывается.
6. Чужое расписание ребёнку без группы не подставляется; новых запросов к данным нет (используется уже загружаемая выборка `player_guardians`).

### Матчи (Matches, родитель)
7. **Нет детей.** Прежнее пустое состояние («Пока пусто», «Матчи появятся, когда администратор подтвердит связь с ребёнком»).
8. **Все дети без группы.** Состояние «Группа ещё не назначена» с именами детей и пояснением, что матчи появятся после назначения группы. Фраза «подтвердит связь» не используется. Запросов матчей и RSVP не выполняется, как и в прежнем состоянии без групп.
9. **Часть детей без группы, у других группа есть.** Матчи, итоги, RSVP групп отображаются без изменений; над списком показывается короткая заметка «Группа ещё не назначена: Имя» (имена через запятую). Ребёнок без группы не блокирует экран.
10. **Все дети с группами.** Вывод не меняется (заметки нет).
11. Не создаются матчи и RSVP для ребёнка без группы; группа не назначается автоматически.

## Проверки (автотесты, Vitest)
Для каждого экрана отдельно: один ребёнок без группы (условия 2, 8); несколько детей, часть без группы (3, 9); все дети с группами (4, 10); нет привязанных детей (1, 7). Плюс: у администратора карточки нет (5); текст «подтвердит связь» отсутствует в состояниях «без группы» (2, 8).
