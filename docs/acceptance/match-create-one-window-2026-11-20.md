# Условия приёмки: одно окно «+ Матч» (2026-11-20)

Решение Павла 2026-11-20: оставить одно окно «+ Матч». Матч с подтверждением
создаётся по умолчанию, для уже сыгранных матчей есть переключатель.

1. «+ Матч» открывает окно «Добавить матч» с переключателем «Матч уже сыгран,
   ввести результат». По умолчанию он выключен.
2. Переключатель выключен: в окне пояснение и кнопка «Создать матч с
   подтверждением». Она открывает форму «Новый матч» (подтверждение участия).
3. Переключатель включён: окно такое же, как раньше (события, команды, форма
   с результатом, без подтверждения).
4. Меню «⋯» по-прежнему содержит «Матчи с подтверждением» (список и черновики)
   и, для администратора, «Новое событие».
5. В форме «Новый матч» чемпионат выбирается среди событий тренера; команда
   события (в том числе «U13-A», «U9-B») берётся из события (см.
   `ui-fixes-after-review-2026-11-20.md`, п. 5).
6. Переключатель не сохраняется между открытиями: каждый раз выключен.
7. Известная разница, не меняется: товарищеский матч с подтверждением и
   выбранной группой с буквой набирает состав только из этой группы, команда
   матча остаётся без буквы («U13»); старая форма пишет «U13-B».
