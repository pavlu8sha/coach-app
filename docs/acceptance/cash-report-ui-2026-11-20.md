# Кассовый отчёт: вкладки, даты, локация (2026-11-20)

Условия приёмки:
1. Переключатель разделов «Оплаты» (Приём оплат / По месяцам / Должники / Отчёт) на узком экране идёт сеткой 2×2 с обычным шрифтом, без горизонтальной прокрутки.
2. В режиме «Период» поля «С» и «По» занимают две равные колонки на всю ширину.
3. «Локация» — выпадающий список: «Все локации» и значения `sessions.location` без дублей, по алфавиту.
4. Выбор локации передаёт в `cash_report` точное значение из списка (`p_location`), «Все локации» передаёт null. Регистр больше не вводится руками.
5. Если список локаций не загрузился, отчёт всё равно работает (выбор «Все локации»); ошибка списка не блокирует отчёт.
6. Ранее сохранённая локация, которой нет в списке, остаётся выбранной и видна (не пропадает молча).
Без миграций, без изменений финансовой логики.
