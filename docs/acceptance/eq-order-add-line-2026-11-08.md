# Условия приёмки: вещь, добавленная в заказ экипировки, не пропадает

Баг (08.11): в заказе нажали «Добавить в заказ» для «Дождевика», в заказе вещь появилась, но после выхода
из заказа и повторного входа её нет. В базе строка есть.

Причина: «Назад» в мини-приложении (кнопка Telegram и свайп) идёт через стек навигации (`nav.back()`), а не через
обработчик экрана, который перезагружает список. Список заказов остаётся прежним, и заказ открывается по старой копии.

## Условия
1. После «Добавить в заказ» (в т.ч. с пустым размером) вещь видна в заказе.
2. Выйти из заказа системной «Назад» (nav.back, без перезагрузки списка) и открыть заказ снова: вещь на месте.
3. То же для правки размера/количества, «Убрать», оплаты и даты заказа: повторно открытый заказ показывает актуальные данные.
4. Строка заказа в списке (состав, «оплачено из») после возврата тоже актуальна.
5. Группа игрока в списке (фильтр «Все группы») после обновления заказа не теряется.
6. Ошибка сохранения видна рядом с кнопкой, а не только вверху экрана.
