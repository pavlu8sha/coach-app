# Условия приёмки: поиск ребёнка как шаг навигации (#732)

Источник: аудит #693 (этап «Ребёнок», 19.11.2026), Issue #732. Master `0df4759`.
Область: `web/src/screens/LinkOnboarding.tsx`, `Home.tsx` (родитель) и их тесты. Не меняются: поиск, согласия, статусы запросов, RPC, RLS, общая навигация (`web/src/nav`), #518.

## Проблема
«Найти ребёнка», «Найти другого ребёнка», «Добавить другого ребёнка» и «+ Добавить ещё одного ребёнка» включали локальное состояние (`searching`, `addMore`). Поиск не был записью стека: в Telegram оставался «✕», вернуться к шагам можно было только закрыв приложение.

## Условия
1. **Поиск = запись стека.** Каждое из четырёх действий делает `nav.push('hm.link')`; локального состояния `searching`/`addMore` нет.
2. **Назад.** Системная «Назад» (Telegram, браузер/PWA через общий стек) и кнопка «Назад» на экране (вне Telegram) закрывают запись и возвращают к предыдущему шагу: обзор шагов, «Запрос отправлен», «Ребёнок пока не отображается» или карточки детей. Приложение не закрывается.
3. **Корневой экран.** На обзоре шагов и карточках детей кнопки «Назад» нет.
4. **Повторное открытие.** После возврата поиск открывается снова, поле пустое, состояние обзора (запросы, дети) прежнее.
5. **Политика.** Открытие политики поверх поиска и возврат из неё работают как раньше (поле поиска и выбор сохраняются); кнопка «Назад» экрана поиска при открытой политике не дублируется.
6. **Данные.** Новых запросов нет. Отправка запроса работает как раньше.
7. **Одобрение во время поиска.** Фоновой проверки статуса в приложении нет и не добавляется. Главная обновляется (как после экрана статусов) при выходе из поиска («Назад», системная), поэтому подтверждённый ребёнок виден сразу после возврата. Если `Link` сам увидел одобрение, пока поиск открыт, запись поиска закрывается.
8. **Закрывается именно поиск.** При автозакрытии снимается запись `hm.link` вместе с тем, что открыто поверх неё (политика), а не только верхний экран.
9. **Вне #732.** Администраторская кнопка «Привязать своего ребёнка» (`showLink`), общая навигация, #518, поиск и согласия.

## Проверки (Vitest)
Условия 1-4 для обзора шагов, «Запрос отправлен», «Ребёнок пока не отображается» и «+ Добавить ещё одного ребёнка» (в `LinkOnboarding.test.tsx`, `Home.test.tsx`); 5 — существующий тест политики; 3 — отсутствие «Назад» на корне.
