# Условия приёмки: исправления по замечаниям Павла после слияния #751, #752 (20.11)

Источник: сообщение Павла 20.11 (скриншоты и записи экрана на iPhone в Telegram). Master `a21cbe0`.

## Условия
1. **Меню «⋯» на «Матчах» не перекрывается полями.** Шапка (`.ks-head`) лежит выше следующих за ней полей (stacking context), меню целиком видно поверх выбора команды, пункты не режутся и не переносятся посередине фразы (ширина по содержимому, не больше 320 px и не шире экрана).
2. **Отступ под шапкой.** Между шапкой с кнопками («Игроки», «Матчи») и следующим полем (поиск, выбор команды) 12 px, как у обычного заголовка.
3. **«Группа» (экран баллов): без мигания.** После выбора группы список не показывается сначала по алфавиту, а потом по баллам: до загрузки баллов показывается заглушка загрузки, потом сразу список с местами. Если баллы не загрузились, список остаётся по алфавиту без мест, как раньше.
4. **Главная кнопка Telegram: без вспышки цвета по умолчанию.** При уходе с экрана кнопка сначала скрывается, цвета Telegram возвращаются только через 600 мс и только если кнопку не занял следующий экран. Цвета клуба при показе не меняются.
5. **«Матчи с подтверждением» → «Новый матч», тип «Матч чемпионата»: те же события, что в «Добавить матч».** Предлагаются идущие (не завершённые) события команд тренера, при этом команда события сверяется и с названием группы, и с командой без буквы (событие «U9-B» доступно группе U9-B, «U13-A» группе U13-A); у администратора и тренера всех команд любые события. В названии варианта указана команда события. Команда создаваемого матча берётся из выбранного события (как в `event_add_game`), поле «Команда» при выбранном событии не показывается. Состав чемпионатного матча по-прежнему берётся из списка события. Товарищеские матчи не меняются.

## Проверки (автотесты, Vitest)
Группа: до ответа запроса баллов DOM никогда не содержит имён без «Место N по баллам» (тест красный без правки), при ошибке баллов список по алфавиту (3); кнопка Telegram: сразу после скрытия цвет клуба остаётся, через 700 мс возвращается цвет Telegram, при немедленном новом показе цвета Telegram не возвращаются (4). Событие «U9-B» и «U13-A» доступно и даёт команду матча из события, чужие и завершённые события не предлагаются, администратору видны любые (5). Для 1 и 2 автотеста нет (вёрстка): проверено отрисовкой в Chromium на 390 px; поведение на iOS остаётся на проверку Павла. Полный `npx vitest run`, `tsc`, `npm run build`.

## Честно о проверках
Независимой проверки второй моделью не было (решение владельца 2026-11-11). Миграций нет. Что именно имел в виду Павел под «старой голубой кнопкой» (п. 4), записи не показывают однозначно; принято, что это кнопка Telegram, которая при скрытии на миг получала цвет Telegram по умолчанию. Если вспышка останется, нужна новая запись.

6. **Мигание при открытии разделов «Ещё»** (запись экрана Павла 20.11).
   Причины: «Запросы» и «Игроки» при загрузке показывали полноэкранную
   заставку приложения (Splash) вместо скелетона; у «Матчей», «Баллов игроков»,
   «Тренеров», «Цен», «Настроек клуба» и «Меню» заголовок появлялся рывком после
   данных; каталог «Ещё» проявлялся заново при каждом возврате.
   Условия: (а) пока запросы раздела не ответили, ни один из 24 разделов не
   показывает пустое состояние («пока нет», «ничего не найдено»), заставку
   приложения и всегда показывает свой заголовок; (б) каталог «Ещё» не
   проявляется анимацией при возврате из раздела. Проверка (а) тестом
   `MoreLoading.test.tsx` для всех разделов из `SECTIONS`.
