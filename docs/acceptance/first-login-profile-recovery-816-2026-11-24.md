# Первый вход: восстановление профиля и понятные ошибки (#816)

Дата: 2026-11-24. Приоритет: P0. Продуктовые правила ролей и доступа не меняются, production-данные и миграции не затрагиваются.

## Что проверяем

- **A1.** Если сессия есть, но чтение `users` вернуло ошибку, приложение показывает экран «Профиль недоступен» с повтором, а не выбор роли. Повтор после устранения ошибки открывает нормальный экран.
- **A2.** Если сессия есть, строки `public.users` нет, а в Telegram доступен `initData`, приложение один раз выполняет штатный полный вход `tg-auth`, затем перечитывает профиль. `RoleSelect` показывается только после появления строки с пустой ролью.
- **A3.** Если восстановить вход нечем (нет `initData`) или строка так и не появилась, показывается ошибка профиля с повтором, без ложного экрана первого входа и без бесконечного цикла.
- **A4.** Причины ошибок различаются: `P0002`/`profile_missing` — нет профиля; `42501` без признака сессии — общая ошибка прав; `forbidden`/JWT — ошибка сессии; сетевой сбой — ошибка соединения. Сырые SQL-коды, имена функций и тексты Supabase пользователю не показываются.
- **A5.** Успех сохранения роли подтверждается повторным чтением выбранной роли. Если сессии уже нет, текст говорит о сессии, а не о пропавшем профиле.
- **A6.** `tg-auth` после вставки строки профиля перечитывает её и проверяет, что `users.id` совпадает с id Auth-пользователя. Конкурентная вставка с тем же id считается успехом; строка с другим id даёт `identity_mismatch`/409; ошибка вставки без появившейся строки даёт 500, а не ложный `token_hash`.
- **A7.** Повторный и конкурентный вход не создаёт дублей строки профиля и не выдаёт ложный успех.
- **A8.** RLS, права таблиц и `set_my_role` не ослабляются; новые миграции не нужны. Проверки: web-тесты, Deno-тесты, сборка и CI.

## Чем проверяется

- `web/src/App.test.tsx`: ошибка начального чтения, восстановление отсутствующей строки, повторное открытие без дублей, безопасный отказ без `initData`.
- `web/src/lib/role.test.ts`: классификация причин, подтверждение роли, отсутствие сессии, сетевая ошибка.
- `web/src/screens/RoleSelect.test.tsx`: понятные тексты и отсутствие технических подробностей.
- `tests/deno/tg-auth.test.ts`: чтение после вставки, идемпотентная конкурентная вставка, ошибка без строки, существующие сценарии входа.
- `db/tests/rls_user_role_test.sql` и полный CI: RLS/grants/`set_my_role` без изменений.

## Вне рамок

- Production-миграции, backfill и изменение реальных строк.
- Деплой Edge Functions и секретов.
- Параллельная регистрация или второй источник создания профиля.
