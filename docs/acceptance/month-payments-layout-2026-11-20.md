# Условия приёмки: «По месяцам», плашка суммы (2026-11-20)

Только клиент, миграций нет, деньги не меняются.

1. В карточке игрока раздела «По месяцам» имя и плашка суммы («165 ₾ из 165 ₾») стоят
   в одной строке. Длинное имя (например, «Imanuel Charles McLure») переносится
   внутри своей области на две строки, плашка не уходит под имя.
2. Плашка не сжимается и не переносится по словам.
3. Остальные строки с `ks-line` (взносы, касса, платежи игрока) не меняются.
