# План перехода с Google-таблиц на приложение (подготовка к Issue #18)

Статус: черновик решений, 2026-10-22. Реализация не начата. Источник идеи — [Issue #18](https://github.com/pavlu8sha/coach-app/issues/18).

## Решения владельца (согласовано 2026-10-22)

1. **Тренеры переходят на приложение.** Таблицы остаются только архивом и резервом, новые записи в них не ведутся после переключения.
2. **Родители и группы — в Telegram.** Вход через Telegram, уведомления через бота, приложение открывается как Telegram Mini App.
3. **Платформа:** веб-приложение (PWA), которое открывается и в браузере, и внутри Telegram. Нативное приложение не делаем на первом этапе.
4. **План согласован.**

## Воронка (пробные)

Старая таблица воронки **не переносится**. Она остаётся как есть до конца перехода. Новые пробные вносятся сразу в приложение (таблица `trials`). Телефоны видны только администратору.

## Миграция

1. Схема и импорт: реестр, группы, посещаемость, оплаты, экипировка, матчи.
2. Двойная запись на один сезон, еженедельная сверка скриптом.
3. Переключение чтения на базу. Таблицы — архив.
4. Отключение Apps Script-приложения после сверки.

## Рейтинг и достижения (из Issue #18)

- Правила начисления — отдельная таблица в базе с текстом объяснения для родителя.
- Уважительная причина отсутствия помечается флагом и не снижает баллы.
- Публичный индивидуальный рейтинг выключен по умолчанию, включается клубом.
- Основные режимы: личная динамика и групповой рейтинг.

## Приватность детских данных

Перед сбором данных нужны: согласие родителя, минимум полей, доступ строго по ролям, журнал просмотров, экспорт и удаление по запросу, срок хранения. Короткая юридическая проверка требований Грузии и ЕС для данных несовершеннолетних — до старта.

## MVP первого сезона

- Личная динамика и достижения.
- Групповой рейтинг.
- Переключатель публичного рейтинга.
- Без платежей и экипировки на первом этапе.
