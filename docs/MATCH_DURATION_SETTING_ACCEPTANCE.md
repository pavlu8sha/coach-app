# Длительность матча настройкой: условия приёмки

Продолжение PR #591. Статус «Идёт» у начавшегося матча без счёта раньше держался фиксированные 1,5 часа.
У разных команд матчи длятся по-разному, поэтому длительность становится настройкой клуба.

## Настройка

1. В «Настройках клуба», группа «Матчи», есть поле «Длительность матча, минут — общая».
   Значение по умолчанию 90. Допустимо целое число от 10 до 600.
2. Под ним администратор добавляет своё значение для команды (область = название команды, как у взноса за чемпионат).
   «К общему» убирает значение команды.
3. Ключ в `club_settings`: `matches.durationMin`. Общее значение хранится с пустой областью.

## Статус матча у родителя

4. Счёт внесён: матч уходит из секции «Отменённые и начавшиеся» в «Результаты» общего списка и учитывается в итогах команды, длительность не важна. Отменённый матч остаётся карточкой в своей секции.
5. Счёта нет, с начала прошло меньше длительности матча: «Идёт».
6. Счёта нет, прошло не меньше длительности: «Прошёл, результат не внесён».
7. Длительность берётся так: значение команды матча, иначе общее, иначе 90. Название команды сравнивается без учёта регистра и пробелов по краям.
8. Если значение не читается, пустое или недопустимое (не число, дробное, вне 10–600), действует следующее по порядку из п. 7.
   Экран родителя из-за настройки не ломается.

## Доступ

9. Родитель читает настройку функцией `match_duration_minutes()`. Таблица `club_settings` остаётся доступной только администратору.
10. Функция отдаёт только ключ `matches.durationMin` и только клуба, где у вызывающего есть ребёнок с действующей связью.
    Администратор видит значения всех клубов. Приложение работает с одним клубом: родителю с детьми в двух клубах функция отдаёт строки обоих, и приложение их не различает (club_id не отдаётся). Если клубов станет больше одного, функцию нужно доработать.
11. Пользователь без детей получает пустой список. Гость без входа вызвать функцию не может.
12. Другие ключи настроек (взносы, скидки, лимиты) функция не отдаёт.

## Данные и миграция

13. Миграция 0168 только создаёт функцию. Таблицы, политики и данные не меняются.
14. Пока миграция не применена, приложение работает со значением 90.
