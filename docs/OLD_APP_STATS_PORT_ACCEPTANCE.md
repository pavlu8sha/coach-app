# Перенос статистики из старого приложения: условия приёмки

Источник: скрины старого приложения (Apps Script) от 27.11.2026. Решение Павла: ничего из нового приложения не убираем, только дополняем (бомбардиры остаются); «написал(а)» в «Должниках» не переносим. Без миграций и без новых функций базы.

## A. «Учёт тренеров → Статистика»: тренер раскрывается в список тренировок
- A1. Строка тренера в `StaffStats` раскрывается (нативный `details`), в сводке остаются прежние цифры и процент регламента.
- A2. В раскрытом списке: «дата · группа» и часы, по возрастанию даты; только проведённые (`held = true`) за период тренера.
- A3. Часы в списке показываются, только если `trainer_stats` вернула часы (администратору); тренеру часы не показываются, как в сводке.
- A4. Список читается из `training_log` лениво, при первом раскрытии; ошибка чтения показывается строкой в раскрытии, сводка не страдает.
- A5. Тренер без проведённых тренировок (только игры): раскрытия нет.

## B. «Статистика → Матчи»
- B1. Над командами сводка за период по всем показанным матчам: игр, голы «забито:пропущено», разница, побед, ничьих, поражений; побед/ничьих/поражений с цветными значками В / Н / П.
- B2. Раскрывающийся список «Последние матчи» (до 10, новые сверху): «дд.мм · команда — соперник», счёт, значок В/Н/П. Матчи без счёта не показываются.
- B3. Фильтр «Все команды» по команде: сводка и список считаются только по выбранной команде; секции команд ниже сокращаются до выбранной.
- B4. Прежнее остаётся: период, вид матчей, плитки по командам, серия побед, лучший матч, бомбардиры, список игроков.
- B5. При выбранном виде матчей (не «Все матчи») список матчей не загружается (вид матча в `matches` не виден), поэтому «Последние матчи» не показываются; сводка считается по `match_stats`.

## C. «Статистика → Посещаемость»
- C1. Период «Прошлая неделя» (понедельник–воскресенье предыдущей недели) добавлен к «Месяц / Прошлый / Период»; период хранится как прежние.
- C2. Сводка: «групповых тренировок» (сумма занятий групп), «N из M отметок „был“» (M = игроки × занятия по группам), общий процент.
- C3. Каждая группа — раскрывающаяся карточка: название, процент, полоса; в раскрытии игроки по возрастанию посещений (как сейчас, с порогом `stats.lowPct`).
- C4. Прежняя строка «Занятий: N · игроков: K · посещаемость P%» остаётся внутри раскрытия.
- C5. Пустой период и ошибки: прежние тексты.

## D. Правки по проверке на iPhone (27.11)
- D1. Плитки «побед / ничьих / поражений»: значок В/Н/П стоит рядом с числом, не переносится на отдельную строку.
- D2. Команда одна (выбрана фильтром или единственная): плитки команды не дублируют сводку, остаются «Серия побед» и «Лучший матч». Несколько команд: у каждой полный набор, как раньше.
- D3. «Учёт тренеров → День»: время тренировки отдельной строкой под названием, без висящей точки.
- D4. «Учёт → Статистика»: тренер одной карточкой (имя, сводка, процент, шеврон внутри карточки), раскрытие под разделителем, часы выровнены по правому краю.
- D5. Период «Эта неделя» (понедельник–сегодня) в «Посещаемости» и «Матчах»; раньше был только «Прошлая неделя» (упущение).
- D6 (граничные случаи после тестирования #845). Карточка тренера без процента регламента, без часов и без тренировок, а также длинное название группы в раскрытом списке переносятся внутри карточки на 320 px, не выходя за край; у `summary` есть `aria-expanded`.
- D7. Одна команда без матчей со счётом и без плиток: после сводки нет пустой карточки (только заголовок команды).
- D8. «Эта неделя» и «Прошлая неделя» считаются в `lib/seasonStats.ts` (`thisWeek`, `prevWeek`): понедельник, воскресенье, граница месяца и года покрыты тестами; «Эта неделя» передаёт период и в `attendance_stats`, и в `match_stats`.
- D9. (снято, см. F) «Сезон» в «Посещаемости» не было намеренно до решения Павла 27.11.

## E. Светофор посещаемости (решение Павла 27.11)
- E1. «Статистика → Посещаемость»: полоса группы и плашка игрока красные ниже порога низкой посещаемости (`stats.lowPct`, 50), жёлтые от него до порога хорошей, зелёные от `stats.highPct` (новая настройка клуба, по умолчанию 80). Границы: ровно 50 жёлтый, ровно 80 зелёный.
- E2. Неверный порог (не число, вне 0–100) или высокий ниже низкого: подсветки нет (полоса синяя, плашки нейтральные), над списком сообщение.
- E3. Цвет полосы идёт из `--ks-warning-fill` (светлее текстового `--ks-warning`); общий класс `.ks-bar` не менялся, цвет задан на этом экране.
- E4. Без миграций: настройка читается из `club_settings` общим механизмом.

## F. «Сезон» в «Посещаемости» (решение Павла 27.11: одинаково с «Матчами»)
- F1. В «Статистика → Посещаемость» добавлен период «Сезон» между «Прошлый» и «Период»; охват как в «Матчах»: с 1 сентября (до сентября — прошлого года) по сегодня (`seasonStart`).
- F2. «Сезон» передаёт этот период в `attendance_stats`; период хранится как прежние (`st.att.range`).
- F3. Остальное (сводка, светофор, раскрытие групп) не меняется; в пределах лимита 13 месяцев сервера (сезон не длиннее 12 месяцев).
- F4. D9 снято: «Сезон» в «Посещаемости» теперь есть.
