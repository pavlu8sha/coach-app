# Финальный импорт перед переходом тренеров (сб 31.10, вечер)

Выгрузку и запуск делает владелец. Время: 30–40 минут. Нужен ноутбук с папкой проекта (`git pull`), Node.js и переменными `SUPABASE_URL`, `CLUB_ID` (как в `scripts/import/README.md`).

## 0. Условия
- Все тренировки субботы закончились: после выгрузки старое приложение для отметок больше не используется (воскресенье — только новое).
- Вы под рукой, пока идёт импорт: остановки — только при ошибках.

## 1. Выгрузить листы в CSV (Apps Script)
1. Откройте проект Apps Script старого приложения.
2. «Настройки проекта» → «Свойства скрипта»: задайте `MAINT_UNTIL` = время окончания окна, формат `ГГГГ-ММ-ДД ЧЧ:ММ` (не дальше 60 минут от сейчас), например `2026-10-31 20:30`.
3. В редакторе выберите функцию `migrationExport` и нажмите «Выполнить». В журнале появится ссылка на папку `migration-export <дата время>` в Google Диске.
4. Скачайте папку на ноутбук (Диск → скачать; распакуйте архив). Внутри подпапки `ATT_ID`, `PAY_ID`, `ADMIN_ID`, `GAMES_ID`, `EQUIP_ID`, `IND_ID`, `GN_FILE`.
5. Закройте окно: удалите значение `MAINT_UNTIL` (или оно закроется само).

## 2. Проверка без записи
PowerShell, папка проекта:
```powershell
$env:SUPABASE_URL = "https://ypxbwhjsqkrciozdhajf.supabase.co"
$env:CLUB_ID = "<id клуба>"
.\scripts\import\final-import.ps1 -Dir "C:\путь\migration-export 2026-10-31 19-05" -Mode Final -ShowOnly   # показать команды
.\scripts\import\final-import.ps1 -Dir "C:\путь\migration-export 2026-10-31 19-05" -Mode Final              # проверка (ключ спросит)
```
Если на компьютере политика `AllSigned` и `.ps1` не запускается, используйте то же на Node (подпись не нужна), `--write` вместо `-Write`:
```powershell
node scripts/import/final-import.mjs --dir "C:\путь\migration-export 2026-10-31 19-05" --mode Final --show-only
node scripts/import/final-import.mjs --dir "C:\путь\migration-export 2026-10-31 19-05" --mode Final
```
Без `-Write` ничего не записывается. Посмотрите вывод каждого шага: числа игроков, посещаемости, матчей. Любая ошибка «Остановка: шаг …» — пришлите мне текст (ключ в нём не бывает).

## 3. Запись
```powershell
.\scripts\import\final-import.ps1 -Dir "C:\путь\migration-export 2026-10-31 19-05" -Mode Final -Write
```
Скрипт идёт по порядку: игроки, даты рождения, расписание и журнал тренировок, **посещаемость**, **матчи**, оплаты, индивидуальные, экипировка, сборы, баллы за тренировки; в конце сам запускает `verify.mjs` (сверка с выгрузкой). Повторный запуск безопасен (слияние по внешним ключам).

## Что импорт не трогает и что может перезаписать
- **Матчи** импортируются только новые (`--new-only`): существующие матчи, их состав, голы и названия команд не меняются (в новом приложении переименованы команды, дополнены составы). Исключение: у существующих **товарищеских** матчей, где в базе нет ни одного игрока, участники из колонки `Played` дописываются (существующие строки не перезаписываются). Взносы за матчи и штат новых матчей импортируются.
- Импорт **перезаписывает** (слиянием) данные импортированных записей: имя, группу и статус игрока, расписание, суммы и оплаты заказов экипировки, оплаты абонементов, записи индивидуальных (отметки посещения не трогает). Поэтому до перехода администраторов эти разделы правят только в старом приложении.
- Отличия, которые покажет `verify.mjs` и которые ожидаемы: новые игроки, заказы и оплаты за период после прошлого импорта; в составах матчей «лишние в базе» — это игроки, добавленные вручную в новом приложении (импорт их не удаляет).

## 4. После записи
1. В приложении под администратором: «Ещё → Пересчёт баллов за матчи».
2. `verify.mjs` без расхождений. Если есть, пришлите вывод до воскресенья.
3. **С этого момента посещаемость и матчи больше не импортируем.**

## 5. Дальше, пока администраторы в старом (до 15.11)
Раз в 1–2 дня или перед важным (сбор оплат, рассылка долга):
```powershell
.\scripts\import\final-import.ps1 -Dir "C:\путь\новая выгрузка" -Mode Daily -Write
```
Режим `Daily` не трогает посещаемость и матчи.

## Если не получается
- `Окно обслуживания закрыто`: шаг 1.2, время не дальше 60 минут от текущего.
- `Нужен ровно один файл`: в выгрузке не хватает листа или он назван иначе; пришлите мне список файлов (`Get-ChildItem -Recurse` по папке).
- Ничего страшного не случится при остановке на середине: импорт безопасно повторить с начала.
