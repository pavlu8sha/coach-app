# Условия приёмки: мигание «Баллов» и прыжок «Мои дети» (скринкасты Павла 24.11)

Без миграций. Источник: три скринкаста iPhone; Павел подтвердил 26.11.2026: вкладки открываются сразу, «Баллы» с миганием; строка «Проверяю привязку аккаунта…» в «Мои дети» это баг.

1. Первое открытие вкладки «Баллы» (родитель, ребёнок, тренер): вместо пустого места и схлопнутой страницы показывается карточка «Баллы» с заглушкой (`aria-busy`), затем содержимое.
2. Повторное открытие вкладки: баллы показываются сразу (из памяти приложения), без заглушки и без пустого экрана; свежие данные подтягиваются в фоне и заменяют показанные.
3. При открытии карточки игрока баллы подгружаются заранее (`prefetchPoints`), чтобы первое открытие вкладки было мгновенным; ошибка предзагрузки молча игнорируется.
4. Ошибка загрузки без сохранённых данных по-прежнему показывает «Не удалось загрузить баллы» с повтором, а не пустой список. Если сохранённые данные есть, а фоновое обновление упало, остаются сохранённые.
5. «Мои дети»: пока проверяется привязка аккаунта, строка «Проверяю привязку аккаунта…» занимает ту же высоту, что кнопки «Код для ребёнка» и «Отвязать аккаунт ребёнка» (`ks-back`), страница не сдвигается после проверки.

## Дополнение: «Мои дети» без заглушки при повторном открытии (по записи Павла 26.11)
- Повторное открытие «Мои дети»: список детей и последний известный статус привязки («Код для ребёнка» / «Отвязать») видны в первом кадре, без заглушки и без «Проверяю привязку…».
- Свежие данные и статус подтягиваются тихо; если привязка изменилась, кнопка меняется после ответа.
- Первое открытие после запуска приложения: заглушка и «Проверяю…» как раньше.
- Выход из аккаунта и смена пользователя забывают запомненных детей; чужих детей не видно.
- После отзыва согласия и других перезагрузок списка действия по коду по-прежнему скрыты, пока статус не проверен заново (тесты #735 без изменений).
