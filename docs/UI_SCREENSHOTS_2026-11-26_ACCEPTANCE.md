# Условия приёмки: правки вёрстки по скриншотам Павла (26.11.2026)

Без миграций и без изменений данных. Источник: 8 скриншотов iPhone (Telegram Mini App) от 24.11.

1. «Отметки»: поле даты (с родным оформлением iOS) не шире своей колонки: `width: 100%`, `min-width: 0`, `max-width: 100%`, обрезка выступающего. Проверка на iPhone вручную.
2. «Доп. посещения»: строка гостя переносится; имя гостя занимает всю первую строку (`flex: 1 1 100%`), сумма, статус и кнопки идут под ним. Имя не сжимается до одной буквы.
3. Расписание родителя: у занятий одна локация в одном написании. «Красный парк» и «Red Garden» показываются как «Red Garden» (`canonicalLocation`), в списке расписания групп и в календаре. Строки `weekly_schedule` в базе скрипт 21.11 не трогал: показ нормализуется в приложении, данные не меняются.
4. Календарь родителя: заголовки «Ноябрь 2026 г.» и «24 ноября 2026 г.»: заглавная только первая буква, «г.» строчная.
5. Карточка ребёнка у родителя: одна кнопка «назад». В Telegram работает кнопка Telegram, экранная «Назад» не рисуется; в браузере экранная остаётся.
6. Окно «Записать платёж?»: слова с дефисом («U7-A») не разрываются по дефису; перенос только между словами.
7. Сбор → «Записать игрока» → группа: плашка с суммой («0 ₾ из 1350 ₾») стоит в одной строке с именем справа, не на отдельной строке; заголовок раскрытой группы не перекрыт строкой игрока.

Не меняется: «голов: N» в карточке ребёнка у родителя (решение владельца 26.11: родитель видит голы своего ребёнка).
