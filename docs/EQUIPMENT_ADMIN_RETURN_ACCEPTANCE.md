# «Экипировка» (админ): после создания и удаления заказа остаёмся на списке

Жалоба Павла 24.11.2026: после создания или удаления заказа в разделе «Экипировка» приложение выбрасывает на страницу «Ещё».

Причина: `done()` в `web/src/screens/Equipment.tsx` вызывал `nav.backToRoot()`, который закрывает весь стек раздела, включая сам экран экипировки, и возвращает на «Ещё».

1. После «Создать заказ» закрывается только экран «Новый заказ»; виден список экипировки (заголовок «Экипировка»), стек под ним не меняется.
2. После удаления заказа закрывается только карточка заказа; виден список экипировки; список перезагружается.
3. Кнопка «Назад» в карточке заказа ведёт на список экипировки, а не на «Ещё».
4. Данные, права, база не затронуты; миграций нет.

Проверка: тест «после создания заказа остаёмся на списке экипировки» в `Equipment.test.tsx` (красный на прежнем коде, зелёный на новом).
