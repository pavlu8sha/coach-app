# Матч именно группы U13-B, а не всей команды U13 (миграция 0193)

Условия приёмки. Тесты пишутся от них: `db/tests/rls_match_group_team_test.sql`, `web/src/screens/CoachMatches.test.tsx`.

## Проблема
С миграции 0055 команда нового матча записывается без буквы группы (U13-A и U13-B → «U13»), состав берётся из всех групп команды. Товарищеский матч только U13-B (например, против Ortachala U12) создать как матч этой группы нельзя: он становится матчем «U13» с детьми U13-A, U13-B и U13-C.
Решение владельца (2026-11-13): нужен выбор именно группы. Поведение по умолчанию не меняется, группа выбирается явно.

## Условия приёмки
1. Новая функция `set_match_team_group(m uuid, g uuid, exact boolean)`. Её вызывают администратор и тренер (`is_any_coach()`), как `save_match`. Родитель, игрок, посторонний, неавторизованный: `42501`.
2. `exact = true`: `matches.team` становится названием группы (`U13-B`). `exact = false`: название без буквы группы (`U13`), как до этого.
3. Группа должна быть из клуба матча, а её название без буквы должно совпадать с командой матча без буквы (команда матча `U13` или `U13-B` подходит группе U13-B; `U13-A` и `U12` не подходит). Иначе ошибка `group not in match team`, матч не меняется.
4. Несуществующий матч: `match not found`; несуществующая группа: `group not found`.
5. Матч турнира или события (`tournament_id` не пустой) не меняется: ошибка `tournament match`.
6. Счёт, дата, соперник, состав, баллы и взносы функция не трогает.
7. Видимость: тренер и родитель игрока U13-B видят матч `U13-B` (`can_see_team`, точное совпадение с названием группы); родитель игрока только из U13-A не видит.
8. Права на функцию: `execute` у `authenticated`, нет у `anon` и `public`; проверяется на базе с привилегиями по умолчанию Supabase.
9. Экран новой формы матча: если выбранная группа с буквой (U13-B), показывается галочка «Матч только этой группы (U13-B)». По умолчанию выключена (поведение прежнее). Включена: в составе только дети выбранной группы, после сохранения вызывается `set_match_team_group(..., true)`. У уже сохранённого матча галочка включена, если его команда равна названию группы; её снятие вызывает `exact = false`.
10. Матч с командой «U13-B» открывается для правки с выбранной группой U13-B и составом из записанных игроков.
11. Статистика (`match_stats`) показывает матчи `U13-B` отдельной командой «U13-B»; это принимается как следствие решения владельца.
12. Продуктовое правило соблюдено: тексты без акцента на голах и сравнений детей.

## Не входит
Не меняем `save_match`, `save_match_team`, RLS-политики, баллы и старые матчи. Не применяем миграцию в проде: только Павел после `db/ops/preflight.sql`.
