# Матч: блок «Приглашённые» и вспышка в «Мероприятиях» (условия приёмки, 27.11.2026)

Только веб (`CoachRsvp.tsx`, `ClubEvents.tsx`, `kit.css`); базы и правил не меняем, функции сохраняем.

- R1. Фильтр «Все / Будут / Не будут / Не ответили» — одна строка из четырёх равных кнопок: число крупно, подпись мелко; доступное имя «Подпись (N)» не меняется.
- R2. Игроки — один список в одной карточке (без карточки в карточке): аватар, имя, группа и «отметил тренер/родитель» в одной строке, статус пилюлей справа (Будет — зелёная, Не будет — красная, Не ответил — нейтральная).
- R3. Под игроком одна строка действий: «Будет» и «Не будет» (выбранный закрашен) и ссылка «Убрать»; доступные имена «Игрок: Будет», «Убрать из состава: Игрок» прежние; в черновике только «Убрать», после начала матча действий нет.
- E1. Экраны «Мероприятий» (список, карточка, форма, добавление, карточка участника) не используют плавное появление при смене экрана (`ks-still`): при возврате «назад» нет вспышки.
- Проверки: тесты по R1–R3, E1; `npm run build`; полный `npx vitest run`; скриншот 390 px.
