# Поиск ребёнка для привязки: слова в любом порядке, кириллица, подсказка (миграция 0198)

Условия приёмки. Тесты: `db/tests/rls_link_search_words_test.sql`, `web/src/screens/Link.test.tsx`.

## Проблема
Первый реальный родитель (2026-11-16): поиск находил ребёнка только по первым буквам фамилии, по имени никого; просит указать, что имена вводятся латиницей. Причина: `search_players_for_link` ищет всю введённую строку как кусок `players.full_name` (порядок «Фамилия Имя»). «Max Ivanov» не находит «Ivanov Max», кириллица не находит латинское имя.

## Условия приёмки (база)
1. Запрос режется на слова по пробелам (берутся первые 4). Ребёнок подходит, если **каждое** слово встречается в `full_name` в любом порядке. «Ivanov Max» и «Max Ivanov» дают одного и того же ребёнка.
2. Минимум не ослаблен: запрос короче 3 символов после trim даёт пустой результат; нужно хотя бы одно слово от 3 символов («Ma Iv» не ищет). Остальные слова только сужают выдачу.
3. Кириллица находит латиницу и наоборот: сравнение идёт и по исходному тексту, и по нормализованному (`link_search_norm`: кириллица в латиницу, kh→h, x→ks, c/q→k, y/j→i, w→v, повторы букв схлопываются). «Макс» находит «Max», «Иванов Макс» находит «Ivanov Max». Нормализованное слово учитывается только от 3 символов (иначе «ааа» превратилось бы в «а» и находило бы всех).
4. Не меняется: лимит 5, rate limit 30 за 10 минут (`54000 search limit reached`), только свой клуб, только `active`, скрыты дети, уже привязанные родителю или с его запросом, `not authenticated` без входа, функция volatile, сортировка по имени.
5. `%`, `_`, `\` в запросе не работают как маски (как раньше).
6. Приватность: пустой, короткий и состоящий из спецсимволов запрос ничего не возвращает; строк не больше 5.
7. `link_search_norm(text)`: immutable; execute нет у `public`, `anon`, `authenticated` (внутренняя, вызывается из definer-функции), проверяется на базе с привилегиями по умолчанию Supabase. Права `search_players_for_link` не меняются.
8. Откат: `db/ops/rollback-0198-link-search-words.sql` возвращает тело 0173. Прод: применяет только Павел после `db/ops/preflight.sql` (строка 0198 в preflight).

## Условия приёмки (экран «Добавить ребёнка»)
9. Плейсхолдер поля «Ivanov Max»; подсказка под полем: имя и фамилия вводятся латиницей, как в заявке клуба, порядок не важен; кириллица тоже работает.
10. Текст «Ничего не найдено» напоминает про латиницу и любой порядок слов.
11. Минимум 3 буквы и остальное поведение экрана не меняются.
