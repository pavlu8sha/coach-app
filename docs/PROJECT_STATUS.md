## Ветки

На момент инвентаризации были найдены 18 веток. Для 15 старых веток дизайна/настроек сравнение с `master` показало `ahead_by = 0`: уникальных коммитов, отсутствующих в `master`, не обнаружено. Это позволяет рассматривать их как кандидатов на удаление, но сами ветки **ещё не удалены**. Перед удалением нужно повторно сверить состояние и убедиться, что ветки не стали активными.

Ветки, которые необходимо сохранить:
- `master` — стабильная интеграционная ветка.
- `stage-abc` — изменения OpenCode; не удалять до завершения review PR #2.
- `perf-phase1` — уникальная работа по производительности; не удалять до решения по Issue #5.
- `chore/repository-governance` — ветка текущего PR #3.

Список проверенных старых веток и результаты сравнения ведутся в [Issue #7](https://github.com/pavlu8sha/coach-app/issues/7). В этой сессии удаление веток не выполнялось.

## Production и deployment

- Production — Google Apps Script web app.
- `/dev` production-проекта использует боевые таблицы и **не является изолированным тестовым окружением**.
- В рамках организационного PR deployment не выполнялся.
- Production deployment SHA/версия должны фиксироваться вручную после контролируемой публикации; не выводить их из состояния GitHub.
