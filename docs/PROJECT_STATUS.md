## Роли и рабочий порядок

- Владелец продукта принимает решения о merge, удалении веток и деплое.
- Исполнитель (OpenCode, другие агенты) работает в своей ветке от `origin/master` и открывает PR. Не редактировать чужую ветку параллельно.
- Один активный исполнитель на одну область кода.
- Успешный CI не заменяет code review.

## Что означает завершение

1. Работа готова в ветке — исполнитель отчитался, тесты и риски указаны.
2. Изменение принято — PR прошёл review/CI и влит в master.
3. Приложение опубликовано — деплой выполнен и подтверждён версией/SHA.

Не смешивать эти статусы.
