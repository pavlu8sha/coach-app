Ветки, требующие отдельного решения:

- остальные старые ветки — сверить уникальные коммиты и только затем архивировать/удалять.

## Production и deployment

- Production — Google Apps Script web app.
- `/dev` production-проекта использует боевые таблицы и **не является изолированным тестовым окружением**.
- В рамках этого аудита deployment не выполнялся.
- Текущий production deployment SHA/версия должны фиксироваться вручную после контролируемой публикации; не выводить их из состояния GitHub.

- [ ] Защищённая ветка `master` и понятные правила слияния.

- [ ] Каждая активная задача связана с Issue и PR.
- [ ] README и правила работы доступны в репозитории.
- [ ] Слияние и deployment учитываются раздельно.
