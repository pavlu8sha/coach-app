## Архитектура и безопасные границы

- Есть старое приложение Google Apps Script и отдельное родительское приложение `web/` (React/Vite + Supabase, Cloudflare Pages).
- Merge в GitHub не означает публикацию Apps Script. Последняя подтверждённая публикация Apps Script в старой документации — 2026-10-22; фактическую версию сейчас не проверяли.
- Отдельной тестовой среды нет. `/dev` Apps Script использует те же боевые таблицы, что и production.
- Не выполнять `clasp push`, deploy, merge, миграции, изменения production-данных или удаление веток без отдельного решения владельца.
- Состояние внешней Supabase БД и фактически применённых миграций **не подтверждено**. Успешный CI не доказывает это и не заменяет code review.

## Правила безопасности

- Владелец продукта принимает решения о merge, deploy, `clasp push`, применении миграций, изменении production и удалении веток.
- Не использовать production или `/dev` для тестовых записей; не запускать импорт на боевых данных.
- Не считать зелёный CI доказательством корректности данных, безопасности или готовности к запуску.
- Разделять статусы: работа в ветке; принято в `master`; опубликовано и подтверждено отдельно.
