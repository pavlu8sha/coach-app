Превью: `cd web && npm run dev`, открыть `/ui-preview.html`.

## Особенности Telegram, которые нужно учесть

1. **Тема.** Telegram передаёт свою палитру (`themeParams`) и светлую/тёмную схему. Сейчас `lib/telegram.ts` целиком перекрашивает приложение в цвета Telegram, поэтому основной цвет — синий Telegram, а не клуба (и в `index.html` `theme-color` ещё зелёный).
2. **Шапка и фон Telegram** (`setHeaderColor`, `setBackgroundColor`) — в цвет фона приложения, чтобы сверху не было полосы другого цвета.
3. **Кнопка «Назад»** (`BackButton`) — для вложенных экранов вместо своей стрелки.
4. **Главная кнопка** (`MainButton`) — для одного главного действия экрана (например, «Отправить запрос», позже у тренера «Сохранить отметки»).
5. **Отклик** (`HapticFeedback`) — короткая вибрация при сохранении и ошибке.
6. **Безопасные зоны** — `viewport-fit=cover` уже стоит; отступы снизу через `env(safe-area-inset-bottom)` заложены в `ks-page`.

## Нужны решения владельца и дизайнера

1. **Тема:** (а) цвета клуба везде, светлая/тёмная по Telegram; (б) полностью цвета Telegram, как сейчас; (в) **гибрид — фон из Telegram, основной цвет клуба (рекомендую):** выглядит родным в Telegram и узнаётся как приложение клуба.
2. **Главное действие экрана:** кнопка Telegram `MainButton` внизу или своя кнопка в экране. Рекомендую `MainButton` для единственного главного действия.
3. **Навигация родителя:** разделов немного (Ребёнок, Расписание, позже Оплаты) — сегментный переключатель сверху, как сейчас, или нижнее меню как у тренеров.
4. **Макеты экранов родителя** от дизайнера — по тем же правилам, что UI-013, до переделки экранов (шаг 2).
